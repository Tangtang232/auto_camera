# 拍好 · AI 引导相机

一个会教你拍照的相机网页 App，给 iPhone 用。AI 在手机上实时看取景画面，用轮廓、箭头和颜色告诉你怎么调整，调好了再按快门。

- **智能引导**：自动区分人像和风景，提示站位（三分线）、别切到头和脚、人物大小、手机拿正、地平线位置，以及侧身、叉腰这类姿势建议。
- **分场景引导**：识别美食、宠物、城市、夜景、日落，按场景给建议。比如美食从斜上方或正上方拍、宠物蹲下来平视、楼房别仰着拍、夜景拿稳、日落多留天空。认错了点左上角徽标手动选。
- **照着拍 · 出片模板**：11 个模板（给别人拍 8 个、自拍 3 个），比如小长颈鹿站姿、走路抓拍、坐台阶、撩头发、45° 俯拍比耶。选一个，照着半透明人形和虚线骨架摆姿势，「要点」卡片写着怎么摆、手机怎么拿，手机角度不对也会提示；拍完自动套上模板配套的色调。模板里的姿势是用骨架参数生成的，不来自任何人的照片。
- **照着拍 · 相册参考图**：从相册选一张喜欢的照片。有人就对齐姿势（虚线骨架和相似度），没人就用半透明叠图对齐构图；拍完把照片的颜色往参考图靠（照着调色）。
- **AI 推荐取景**：GAIC 构图模型每秒给画面里 90 个候选取景框打分，用黄色虚线框标出最好看的那个，引导你走近或转动手机。
- **光线判断**：提示逆光、太暗、大面积过曝。
- **拍后自动出片**：AI 裁剪构图、自动校正曝光和白平衡，再套上风格：用模板拍的用模板配套的色调，用相册参考图拍的照着参考图调色，其他按场景选（人像奶油、美食、萌宠、城市、夜景、日落，其他用清透或胶片）。人像色调有日系、奶油、胶片、暗调四种。城市照片按拍摄时的仰角把歪掉的楼拉直一点，夜景去彩色噪点，逆光人像单独提亮脸。在相册里点照片可以换风格、按住对比原图。
- **人像后期**：人像照片拍完自动做背景虚化和轻度磨皮。用 MediaPipe 多类别人像分割模型分出人和皮肤，遮罩按照片本身细化边缘；只用背景像素做模糊，人物边缘不出光晕；全身照脚下的地面保留一些清晰度。磨皮用导向滤波，只动皮肤，五官和轮廓保留。查看器里可以分别关掉。
- 识别和处理全部在手机上完成，画面和照片不会上传。第一次打开会下载约 35 MB（姿态模型约 6 MB、场景分类模型约 5.4 MB、构图模型约 12.5 MB、ONNX Runtime 约 11 MB），第一次给人拍照前再下载约 16 MB 的分割模型，之后可以离线用。第三方组件见 [NOTICE.md](NOTICE.md)。

## 在 iPhone 上用

1. 用 Safari 打开 GitHub Pages 地址。
2. 点「分享 → 添加到主屏幕」。
3. 从主屏幕图标打开，允许使用摄像头；点一下画面开启水平仪。
4. 拍完点左下角缩略图，「存到相册」后在菜单里选「存储图像」。

## 本地预览

```bash
python -m http.server 5173
```

打开 `http://localhost:5173/?demo` 看演示（不需要摄像头），`?demo&mode=match` 看照着拍的演示，`?demo&scene=food`（或 `pet`、`city`、`night`、`sunset`）看各场景的引导演示，`?demo&mode=match&template=giraffe`（模板编号见 `js/templates.js`）看模板从摆姿势到「可以拍了」的过程。

## 测试

node --test "test/*.test.js"

## 代码结构

| 文件 | 内容 |
|---|---|
| `js/guide.js` | 智能引导规则、地平线检测 |
| `js/scene.js` | 场景识别（分类标签分组、防闪烁）和分场景引导 |
| `js/classify.js` | 加载和调用 MediaPipe 场景分类模型 |
| `js/frame.js` | AI 推荐取景：90 个候选框、选框和提示 |
| `js/light.js` | 光线判断 |
| `js/develop.js` | 拍后出片：自动校正、各场景风格、夜景去噪、人像补光 |
| `js/perspective.js` | 城市照片的竖直透视校正 |
| `js/segment.js` | 拍照时用 MediaPipe 分割出人和皮肤 |
| `js/portrait.js` | 人像后期：遮罩细化、背景虚化、磨皮 |
| `js/ai-worker.js` | 后台线程：构图模型打分、照片处理 |
| `js/match.js` | 照着拍：姿势比对、构图对齐 |
| `js/templates.js` | 出片模板库：姿势参数、构图、机位、要点、配套色调 |
| `js/rig.js` | 用关节角度生成 33 个姿态关键点 |
| `js/figure.js` | 画小人：演示画面、模板卡片、取景叠图 |
| `js/geom.js` | 关键点几何工具 |
| `js/draw.js` | 取景框上的引导图层 |
| `js/pose.js` | 加载和调用 MediaPipe 姿态模型 |
| `js/app.js` | 相机、主循环、界面 |
| `js/demo.js` | 演示模式的合成画面 |
| `js/store.js` | 照片暂存（IndexedDB） |
| `sw.js` | 离线缓存 |
